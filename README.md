# TikTok Studio Upload Helper

Комплект из трёх компонентов для загрузки видео в TikTok Studio одной строкой:
собрал строку в GUI → вставил в панель браузера → кликнул «Сделать всё».

## 📦 Что внутри

| Файл | Назначение |
|------|-----------|
| `tiktok_bridge.py` | Локальный HTTP-сервер (127.0.0.1:8765). Отдаёт видеофайл в браузер с поддержкой Range-запросов и CORS. |
| `tiktok_studio_helper_light.user.js` | Userscript для Tampermonkey. Рисует панель прямо в TikTok Studio, разбирает строку, заполняет описание и загружает видео через bridge. |
| `tiktok_string_builder.py` | Десктоп-приложение на PySide6 — собирает строку (путь, хештеги, дата, описание) и копирует её в буфер обмена. |
| `requirements.txt` | Зависимости для приложения-сборщика (только `PySide6`). |
| `start_*.bat` / `start_*.sh` | Скрипты запуска одним кликом для Windows / Linux / macOS. |

## 🚀 Быстрый старт

### 1. Клонируй репозиторий и установи зависимости

```bash
git clone https://github.com/CLINIOI/tiktok_bridge.git
cd tiktok_bridge
pip install -r requirements.txt
```

### 2. Запусти bridge и сборщик строки

На Windows — двойной клик по `start_all.bat`.
На Linux / macOS:
```bash
./start_bridge.sh &
python3 tiktok_string_builder.py
```

Если всё ок, в окне bridge появится:
```
TikTok Studio Bridge started on http://127.0.0.1:8765
```
Проверка: открой в браузере http://127.0.0.1:8765/health

### 3. Установи userscript в Tampermonkey

1. Открой расширение Tampermonkey → «Создать новый скрипт»
2. Удали всё содержимое, вставь `tiktok_studio_helper_light.user.js`
3. Сохрани (Ctrl+S)

### 4. Открой TikTok Studio

Перейди на https://www.tiktok.com/tiktokstudio/upload — справа появится плавающая панель **TT Helper LIGHT v2.2**. Её можно перетаскивать за шапку и сворачивать кнопкой «—».

## 🎬 Как это работает

```
┌─────────────────────┐   генерит строку    ┌─────────────────────┐
│  String Builder GUI │  ─────────────────▶ │     Буфер обмена    │
│   (PySide6, локал.) │                     └──────────┬──────────┘
└─────────────────────┘                                │ вставляешь
                                                       ▼
┌─────────────────────┐   HTTP (/check,     ┌─────────────────────┐
│   tiktok_bridge.py  │ ◀─── /file) ─────── │  Userscript (панель)│
│  127.0.0.1:8765     │                     │  в TikTok Studio    │
└──────────┬──────────┘                     └──────────┬──────────┘
           │ читает видео с диска                      │ передаёт File
           ▼                                           ▼
    D:\Videos\cat.mp4                          input[type=file]
```

## 📝 Формат строки

### Формат с разделителем `|` (генерируется приложением)

```
D:\Videos\cat.mp4 | #cats #funny #pet | 2026-04-25 18:30 | Мой кот делает что-то смешное
```

### Формат `key=value` (можно писать вручную)

```
path=D:\Videos\cat.mp4; tags=#cats #funny #pet; date=2026-04-25 18:30; caption=Мой кот
```

Поля `date` и `caption` необязательны. Разделитель `|` внутри полей автоматически заменяется, чтобы не сломать парсер.

## 🖥️ String Builder — возможности

- выбор видеофайла через диалог (`Ctrl+O`)
- нормализация хештегов: `cats, funny` → `#cats #funny`, дубликаты удаляются
- опциональная дата публикации с календарём
- предпросмотр готовой строки в реальном времени
- проверка связи с bridge прямо из окна
- **история из 10 последних строк** — одним кликом восстанавливает все поля
- сохранение последнего пути и тегов между запусками (`~/.tiktok_bridge/string_builder.json`)
- горячие клавиши: `Ctrl+B` — собрать, `Ctrl+Enter` — скопировать, `Ctrl+O` — выбрать файл

## 🎛️ Панель в TikTok Studio

| Кнопка | Что делает |
|--------|------------|
| **Разобрать** | Парсит строку и показывает разобранные поля |
| **Заполнить текст** | Вставляет описание + хештеги в поле caption |
| **Загрузить видео** | Читает файл через bridge и подставляет в `input[type=file]` |
| **Сделать всё** | Разбор + заполнение + загрузка за один клик |

Дополнительно:
- панель можно перетаскивать за шапку
- сворачивается кнопкой «—» в углу
- последняя введённая строка сохраняется между сессиями
- индикатор прогресса загрузки видео

## ⚙️ Конфигурация bridge

Можно переопределить через переменные окружения:

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `TIKTOK_BRIDGE_TOKEN` | `1224444` | Токен для заголовка `X-Token` |
| `TIKTOK_BRIDGE_HOST` | `127.0.0.1` | Адрес прослушивания |
| `TIKTOK_BRIDGE_PORT` | `8765` | Порт |

Если меняешь токен или порт — не забудь поправить их в userscript (`BRIDGE` и `TOKEN` в начале файла).

Bridge проверяет расширение файла (`.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`, `.m4v`, `.mpg`, `.mpeg`) и ограничивает размер до 4 ГБ.

## 🛠️ Устранение проблем

| Проблема | Решение |
|----------|---------|
| «Bridge недоступен» | Запусти `python tiktok_bridge.py` или `start_bridge.bat`. Проверь http://127.0.0.1:8765/health |
| «input[type=file] не найден» | TikTok изменил DOM. Скрипт автоматически ждёт до 5 секунд. Если не помогло — кликни «Выбрать видео» на странице вручную и повтори. |
| «Поле описания не найдено» | Нажми кнопку ещё раз после полной загрузки страницы. |
| Панель не появляется | Проверь, что userscript включён и URL содержит `/upload`. |
| Не запускается сборщик | `pip install -r requirements.txt` |
| Ошибка «Invalid token» в логе bridge | Токен в userscript не совпадает с `TIKTOK_BRIDGE_TOKEN` |
